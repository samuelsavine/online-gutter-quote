Purpose: Gather pricing-critical information without an in-home sales presentation. Universal questions are asked once. Each project has 10 targeted questions plus an optional eleventh free-text response. Unknown is an acceptable answer where measurement or inspection is needed.
Universal questions — every project
G1. What is the project address?  |  Street, city, state, ZIP
G2. What type of property is this?  |  Single-family / townhouse / duplex / condo / commercial / other
G3. Do you own the property?  |  Yes / no / under contract / property manager
G4. When would you like the project completed?  |  ASAP / within 30 days / 1–3 months / 3–6 months / researching
G5. What is your primary objective?  |  Repair / appearance / performance / new installation
G6. What matters most?  |  Lowest price / value / premium quality / speed
G7. Are there known access or property restrictions?  |  HOA / gated / historic / difficult access / none / unsure
G8. Can you upload photos of the project area?  |  Upload / take photos / skip
G9. How should we send your estimate?  |  Email / text / both
G10. Contact details  |  Name / mobile / email
Photo workflow: ask for wide views, close-ups of damage, and a measurement reference when practical. Digital measurements and contractor verification are separate steps; do not represent an unverified estimate as a guaranteed final price.

Implementation guidance
Display one question at a time or in short groups, with a progress indicator; branch based on the project scope.
Allow “not sure” rather than forcing false precision; ask for photos or measurements when the answer materially changes price.
Separate preliminary pricing, measurement verification, permit/code review, and final contractor acceptance.
Store responses in structured fields so each category can connect to its own pricing engine and contractor rate card.
Offer adjacent-project cross-sells only after the initial estimate is delivered.
